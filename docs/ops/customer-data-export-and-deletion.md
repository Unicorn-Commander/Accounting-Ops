## EXPORT

### Identity, database, and scope

PostgreSQL 16 with pgvector; database default **accounting_ops**, configurable with `POSTGRES_DB`. Connection variable names: `DATABASE_URL`, `ADMIN_DATABASE_URL`. No connection strings or credentials belong in an export. Evidence: [`docker-compose.yml@1d3a5d2`](../../docker-compose.yml); [`app/config.py@1d3a5d2`](../../app/config.py).

An ORG is mapped through `public.workspace.uc_org_id` (nullable text, not a workspace UUID). Resolve **every** matching `public.workspace.id`; do not assume one org has one workspace. `uc_registry_id` is a separate nullable UUID bridge. The accounting boundary is `workspace_id`; legal entities inside it use `books.entity.id` plus `workspace_id`. Current tenant schema is **books**, shared by all customers, despite legacy `workspace.postgres_schema` values and old migration comments. Evidence: [`migrations/public/versions/0001_public_initial.py@1d3a5d2`](../../migrations/public/versions/0001_public_initial.py); [`migrations/public/versions/0012_workspace_uc_org_id.py@1d3a5d2`](../../migrations/public/versions/0012_workspace_uc_org_id.py); [`migrations/public/versions/0013_workspace_uc_registry_id.py@1d3a5d2`](../../migrations/public/versions/0013_workspace_uc_registry_id.py); [`migrations/tenant/versions/0001_tenant_initial.py@1d3a5d2`](../../migrations/tenant/versions/0001_tenant_initial.py); [`app/workspace_session.py@1d3a5d2`](../../app/workspace_session.py); [`migrations/tenant/versions/0026_force_rls_shared.py@1d3a5d2`](../../migrations/tenant/versions/0026_force_rls_shared.py).

A PERSON has `public.user_account.id` (local UUID), `uc_uid` (unique identity string), and nullable `email`. `public.workspace_membership.user_id` links the local UUID to `workspace_id`; `entity_scope` further limits access. Authentication resolves the verified Keycloak `sub`; `uc_uid` is its alias, with `sub` winning if they disagree. Email is a discovery aid, not proof of identity or a unique key. Evidence: [`migrations/public/versions/0001_public_initial.py@1d3a5d2`](../../migrations/public/versions/0001_public_initial.py); [`app/auth.py@1d3a5d2`](../../app/auth.py); [`app/tenancy.py@1d3a5d2`](../../app/tenancy.py).

Templates use bound parameters: `:org_id = '00000000-0000-4000-8000-000000000001'` (fictional org text), `:email = 'ana@example.com'`; `:wid`, `:uid`, `:sub` must come from verified resolution, not invented equivalences. Each authorized workspace is handled separately. For a person request, obtain authorization for each workspace and restrict further to the person's records. A person's membership does not authorize releasing the workspace's entire books.

```sql
-- READ ONLY: org discovery, before any per-workspace export.
SELECT id, uc_org_id, uc_registry_id FROM public.workspace WHERE uc_org_id = :org_id;
-- READ ONLY: person discovery; verify the returned identity before binding :uid/:sub.
SELECT id, uc_uid, email FROM public.user_account WHERE lower(email) = lower(:email);
-- READ ONLY: membership discovery for the verified person.
SELECT workspace_id, user_id, entity_scope FROM public.workspace_membership WHERE user_id = :uid;
```

All discovery columns are evidenced above. Run export SELECTs in an independently prepared read-only, consistent-snapshot transaction with `app.current_workspace` pinned transaction-locally to the resolved `:wid` as in [`app/workspace_session.py@1d3a5d2`](../../app/workspace_session.py). Do not disable RLS. An unset GUC can produce empty results; empty results alone do not prove absence. Every tenant SELECT below also explicitly filters `workspace_id`. Public-table RLS differs by table; do not assume the tenant policy covers public tables.

### Export inventory and redactions

The following queries collect candidate records into restricted operator staging. They are not a ready-to-send archive. Review nested JSON, free text, addresses, references, document contents, and attachments for third-party data and embedded credentials. Remove passwords/password hashes, tokens/token hashes, private keys, API keys, bearer/signing/payment URLs, and encrypted credential blobs. OTHER customers' rows must never leave. A shared/global row that cannot be safely partitioned is **withheld**, with its reason recorded. Keep accounting integrity hashes distinct from authentication secrets. No local password/password-hash column was found in the migrations or models; upstream identity-provider storage is NOT FOUND in this repo. Evidence: [`app/auth.py@1d3a5d2`](../../app/auth.py); [`migrations/public/versions/0001_public_initial.py@1d3a5d2`](../../migrations/public/versions/0001_public_initial.py); [`app/models/ledger.py@1d3a5d2`](../../app/models/ledger.py).

Known secret columns are excluded in the SQL below. Object paths are restricted manifest pointers, not authorization to disclose linked bytes. `to_jsonb(t)` includes later columns from the same snapshot; unknown nested content still requires review. Never use an unrestricted database dump. Evidence for each table and its `workspace_id` is in that row; all citations pin commit `1d3a5d2`.
